# Code of Conduct

## The short version

Be decent. Assume good faith. Critique the work, not the person.

## Expected behavior

- Keep feedback specific, respectful, and about the change.
- Accept that a maintainer may say no and should explain why.
- Report security issues privately through [SECURITY.md](SECURITY.md).

Harassment, discrimination, personal attacks, publishing private information,
or deliberately wasting contributor time are not accepted. Continued harmful
behavior after a warning ends participation in this repository.
